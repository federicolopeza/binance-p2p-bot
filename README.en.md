# AutoP2P — Binance P2P bot with rule-based repricing

**Your strategy. Every decision, visible.**

AutoP2P v2 is a cloud platform for Binance P2P / C2C operators. Configure pricing rules, select competitors and review why the engine updates or holds an ad price. Manage ads, orders and chat from a web dashboard without running your own VPS.

## How it works

1. Connect an eligible Binance account using the required P2P API permissions, with withdrawals disabled.
2. Choose a strategy, competitor filters, price limits and operating hours.
3. Start the engine when ready, monitor decisions and pause it from the dashboard.

| Strategy | Purpose |
| --- | --- |
| TOP1 | Calculate a price against eligible competitors within your configured limits. |
| FOLLOW | Follow a selected competitor by nickname. |
| UNIFIED | Select the TOP1 or FOLLOW path based on target configuration. |

Holding a price is a valid decision, not a separate strategy. A calculated price is not proof that an update was applied.

## Access and control

This is a public product resource repository, not downloadable trading software or the service source code. Check the [official website](https://autop2p.dev/en/) for current access, plans and trial terms.

AutoP2P does not custody your funds. You control the rules and when to start the engine. Trading carries risk; no returns, order volume or permanent ranking are guaranteed. AutoP2P is independent and is not affiliated with Binance.
