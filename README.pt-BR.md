# AutoP2P — Bot P2P para Binance com ajuste automático de preços

**Sua estratégia. Cada decisão, visível.**

AutoP2P v2 é uma plataforma na nuvem para operadores Binance P2P / C2C. Configure regras de preço, selecione concorrentes e confira por que o motor atualiza ou mantém o preço de um anúncio. Gerencie anúncios, ordens e chat pelo navegador, sem administrar um VPS.

## Como funciona

1. Conecte uma conta Binance elegível com as permissões de API P2P necessárias, sem habilitar saques.
2. Defina estratégia, filtros de concorrentes, limites de preço e horários.
3. Inicie o motor quando estiver pronto, acompanhe as decisões e pause pelo dashboard.

| Estratégia | Função |
| --- | --- |
| TOP1 | Calcular o preço em relação aos concorrentes elegíveis, dentro dos limites configurados. |
| FOLLOW | Seguir um concorrente selecionado por nickname. |
| UNIFIED | Selecionar TOP1 ou FOLLOW conforme a configuração do alvo. |

Manter o preço também é uma decisão, não uma estratégia separada. Um preço calculado não comprova que a alteração foi aplicada.

## Acesso e controle

Este repositório reúne materiais públicos do produto. Não contém um bot para download nem o código do serviço. Consulte o [site oficial](https://autop2p.dev/pt/) para condições atuais de acesso, planos e testes.

AutoP2P não custodia seus fundos. Você define as regras e quando iniciar o motor. Operar P2P envolve riscos; não há garantia de lucro, volume de ordens ou posição permanente no livro. AutoP2P é independente e não é afiliado à Binance.
